## 作品集看板（网页版互动）

首页往下是一块可交互的看板，把十个项目按时间、阶段、性质、类别四个维度摊开，筛选后十张项目卡会实时联动：

- **项目时间轴**：2022 → 2026 的甘特条，一眼看出哪些项目是并行推进的（彩翼从 2022.10 做到 2026.07，2026 年另有五个个人项目同期完成）。点任一条会平滑跳到对应项目卡并短暂高亮。
- **阶段 × 性质热力**：六阶段 × 三种性质的项目计数，深浅表示密集程度；点格子筛性质，点行名筛阶段。
- **三组筛选**：类别（算法 / 开发 / 产品 / 数据 / 行业）、性质（实战交付 / 自研 / 基于开源的二次开发）、阶段（六阶段），可叠加使用；右上角实时显示命中数与「重置」。
- **分布条**：性质与类别的数量分布，跟着筛选实时变化；被筛掉的项目，其时间条会自动变淡。

全部用原生 JS 实现，无第三方库；筛选状态不入 URL，刷新即复位。

### 性质标注口径

- **实战交付**：在职期间的真实项目，有真实用户与上线记录，涉敏内容已脱敏。
- **自研**：独立完成设计与实现的系统，可现场演示并讲解实现细节。
- **基于开源的二次开发**：以公开课程或开源项目为基线，做二次开发、场景化改造与工程化验证，标注基线来源，不冒充原创。

## 本地构建

```bash
python build.py                   # 生成 index.html
python build.py --pdf             # 生成 portfolio_pdf.html
python build_parts/build_all.py   # 全量：网页版 + PDF + 逐页预览
```

PDF 由 Chrome headless 打印 `portfolio_pdf.html` 得到，需带独立 `--user-data-dir`。

## 技术说明

- 纯 Python 生成静态 HTML，无外部依赖、无 CDN，离线可看，GitHub Pages 直接托管。
- 首页链路图、项目图表全部为内联 SVG（`viewBox` 自适应），文字可选中、可打印；首页节点带级联淡入动画，打印时自动关闭。
- 看板用原生 CSS Grid + 绝对定位百分比排布时间条，原生 JS 做筛选联动，同为内联、零依赖；PDF 版不渲染看板（无交互，改用项目地图与链路图表达结构）。
- 照片转为 base64 data-URI 内嵌，单文件即可完整呈现，PDF 打印不丢图。
- 视觉系统：墨黑 `#101827` / 深海军蓝 `#12324E` / 青 `#0E7C86` / 琥珀 `#D98A1F` / 米白纸底 `#FBFAF7`。
